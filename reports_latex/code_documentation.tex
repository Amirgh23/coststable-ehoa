\section{هدف و دامنه}
این پروژه یک انتخاب‌گر ویژگی پوششی بر پایه الگوریتم بهینه‌سازی کوه‌پیمایی بهبود‌یافته (EHOA) را پیاده‌سازی می‌کند. توسعه پیشنهادی با نام \lr{CostStableEHOA} یک قید سخت بودجه را به فرایند جست‌وجو اضافه می‌کند و هنگام نقض بودجه، ویژگی‌ها را بر اساس نسبت «اطمینان محافظه‌کارانه از سودمندی» به هزینه حذف می‌کند. تابع برازندگی پایه تغییر نکرده است؛ در نتیجه اثر سازوکار تعمیر را می‌توان مستقل از تغییر هدف ارزیابی کرد.

\begin{keybox}
ادعای فنی محدود است: ترکیب تعمیر بودجه‌ای با امتیاز \lr{LCB} حاصل از بازنمونه‌گیری اطلاعات متقابل، درون EHOA. هزینه‌آگاهی، اطلاعات متقابل و تعمیر جواب به‌تنهایی نوآوری محسوب نمی‌شوند.
\end{keybox}

\section{منطق روش پیشنهادی}
برای ویژگی $j$ و بازنمونه‌گیری $b$، اطلاعات متقابل $I_{jb}$ محاسبه می‌شود. امتیاز محافظه‌کارانه برابر است با
\begin{equation}u_j=\max\left(0,\bar I_j-z\,s_j\right),\qquad r_j=\frac{u_j}{c_j}.\end{equation}
اگر هزینه ماسک $\sum_j z_jc_j$ از بودجه $B$ بیشتر باشد، ویژگی فعال با کوچک‌ترین $r_j$ حذف می‌شود تا قید برقرار شود. استفاده از کران پایین باعث می‌شود ویژگی‌ای که میانگین سودمندی بالا ولی نوسان زیاد دارد، بی‌دلیل حفظ نشود.

\subsection{تعمیر دقیق قید بودجه}
\begin{latin}\begin{lstlisting}
def repair_to_budget(mask, costs, budget, utility):
    repaired = np.asarray(mask, dtype=bool).copy()
    while costs[repaired].sum() > budget:
        active = np.flatnonzero(repaired)
        ratio = utility[active] / np.maximum(costs[active], 1e-12)
        repaired[active[np.argmin(ratio)]] = False
    if not repaired.any():
        feasible = np.flatnonzero(costs <= budget)
        repaired[feasible[np.argmax(utility[feasible] / costs[feasible])]] = True
    return repaired
\end{lstlisting}\end{latin}
این قطعه ابتدا یک کپی بولی می‌سازد تا ورودی تغییر نکند. حلقه فقط تا زمان نقض بودجه ادامه دارد. در هر دور، ضعیف‌ترین ویژگی از نظر سودمندی به‌ازای هزینه حذف می‌شود. شرط پایانی از ماسک تهی جلوگیری می‌کند و ارزان‌ترین گزینه را کورکورانه انتخاب نمی‌کند؛ بهترین نسبت سودمندی به هزینه میان گزینه‌های شدنی انتخاب می‌شود.

\subsection{برآورد سودمندی پایدار}
\begin{latin}\begin{lstlisting}
scores = []
for _ in range(n_resamples):

بازنمونه‌گیری فقط روی بخش آموزش بیرونی انجام می‌شود؛ داده آزمون بیرونی در محاسبه امتیاز یا جست‌وجو حضور ندارد. میانگین، قدرت تقریبی رابطه و انحراف معیار، عدم‌قطعیت آن را نشان می‌دهد. پارامتر $z$ شدت محافظه‌کاری را کنترل می‌کند.

\subsection{ادغام با EHOA}
\begin{latin}\begin{lstlisting}
class CostStableEHOA(EHOA):
    def _repair(self, mask):
        return repair_to_budget(mask, self.costs, self.budget, self.utility_)

    def fit(self, X, y):
        self.utility_ = resampled_lcb_utility(X, y, random_state=self.random_state)
        return super().fit(X, y)
\end{lstlisting}\end{latin}
وراثت، تکرار کد پایه را کم می‌کند. تنها نقطه مداخله، تعمیر هر جواب کاندید پیش از ارزیابی است. بنابراین اندازه جمعیت، قوانین حرکت، تبدیل دودویی و تابع برازندگی همان EHOA باقی می‌مانند و مقایسه کنترل‌شده است.

\section{پروتکل اجرا و جلوگیری از نشت داده}
ده دیتاست، پنج روش، دو بذر مستقل و سه چین بیرونی به $10\times5\times2\times3=300$ اجرا منجر شده است. پیش‌پردازش و طبقه‌بند فقط با داده آموزش هر چین برازش می‌شوند. بودجه ۳۰ درصد مجموع هزینه‌هاست؛ هزینه‌ها به‌صورت قطعی از توزیع لگ‌نرمال و مستقل از برچسب تولید شده‌اند. هر ماسک، بذر انتخاب‌گر، هش پیکربندی، زمان و معیارهای آزمون ذخیره شده‌اند.

\section{آزمون‌ها و کنترل کیفیت}
مجموعه آزمون شامل رعایت قید، عدم تولید ماسک تهی، قطعیت در بذر ثابت، صحت ابعاد و سازگاری با EHOA است. نتیجه نهایی: ۲۸ آزمون از ۲۸ آزمون موفق. کنترل پس از اجرا نیز ۳۰۰ ردیف، ۳۰۰ ماسک، صفر کلید تکراری، صفر مقدار گم‌شده و صفر نقض بودجه را تأیید کرد.
